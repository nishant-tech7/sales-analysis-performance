# 📊 Sales Analysis & Performance Dashboard

A data analytics project for analyzing retail sales data and understanding
sales performance using Python, SQL, Pandas, and Streamlit.

## 🚀 Project Overview

This project analyzes retail sales data and provides an interactive dashboard
for exploring sales performance.

The dashboard allows users to filter and analyze sales data and view
important business metrics through tables and interactive visualizations.

## ✨ Features

- 📈 Sales performance analysis
- 🛍️ Product-level analysis
- 🏪 Store/sales analysis
- 📅 Date-based filtering
- 📊 Interactive charts and visualizations
- 🔎 Filtered order details
- 📥 Download filtered sales data as CSV
- 🗄️ SQL-based data analysis
- 🐍 Python-based data processing

## 🛠️ Technologies Used

- Python
- Pandas
- NumPy
- Streamlit
- Plotly
- SQL
- SQLite
- Jupyter Notebook
- Git & GitHub
